# Contributing to Vanessa-AI-Relationship-Agent

Thanks for your interest in contributing! A few quick guidelines:

- File issues for bugs and feature requests; provide reproducible steps and environment details.
- For code changes, open a pull request against the `main` branch.
- Keep changes small and focused; add tests where appropriate.
- Follow existing code style. If adding Python code, prefer type hints and linting.
- Mention the relevant issue number in your PR description.

If you're unsure where to start, check `examples/prompt_examples.md` for small documentation improvements.
